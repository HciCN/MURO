# 游戏社交媒体素材包（Social Media Kit）

> 数据与素材来源：**Steam 官方商店 API**（官方截图、预告片、商店页信息）。
> 整理日期：2026-09-28。共 8 款游戏（原始 feed 的 10 条文章中，2 条为预告/更新汇总，非游戏）。

## ⚠️ 发布前须知

- 截图与预告片版权归各游戏**开发商/发行商**所有，素材本身是官方宣传物料，供媒体与创作者使用；发布时建议注明游戏名、开发商，并附**官方商店链接**。
- 不要标注为“你的原创内容”，也不要与盗版/下载信息一同发布——那会带来侵权风险。
- 1080p 截图可直接发微博/X/小红书；视频为 720p MP4（H.264+AAC），各平台通用。

## 目录结构
```
social-media-kit/
├── README.md
└── NN-游戏名/
    ├── cover.jpg        ← 封面/头图（胶囊图）
    ├── screenshots/     ← 官方游戏截图（1920×1080）
    ├── videos/          ← 官方预告片/实机视频（720p MP4）
    └── info.md          ← 该游戏的发布文案素材
```
