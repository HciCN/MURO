把游戏图片（jpg / png / webp）放进这个文件夹，
然后在 js/games-data.js 的 GAMES 数组里登记：

    {
      name: "游戏名", name_en: "GAME NAME",
      genre: "类型", year: 2026,
      desc: "一句话介绍。",
      image: "assets/games/你的图片.jpg",
      link: "https://你的链接"
    }

建议：宽 1200–1600px（16:9 或 3:2）、jpg、单张 < 400KB、
文件名只用小写字母/数字/连字符。
