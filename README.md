# 🎮 游戏仓库 · Game Vault

一个以 **3D 流体画廊** 陈列游戏资源的静态网站：卡片悬浮成"环"缓慢自转，悬停点亮彩色并弹出巨字标题，滚轮一滚，雕塑摊平成一条时间轴任你穿梭，点击弹出毛玻璃详情浮层。

灵感源自 Obys® Experiment Space 的交互概念，代码为全新原创实现，可自由修改与商用。

---

## 📁 目录结构

```
game-vault/
├── index.html            ← 页面骨架（一般不用动）
├── css/
│   └── style.css         ← 全部样式
├── js/
│   ├── games-data.js     ← ★★★ 你唯一需要常改的文件：站名 + 游戏列表
│   ├── gallery.js        ← 3D 画廊引擎（不用动）
│   └── site.js           ← 站点 UI 逻辑（不用动）
├── assets/
│   └── games/            ← ★ 把你的游戏图片放这里
└── README.md             ← 本说明
```

## 🚀 快速开始

### 本地预览（重要）

WebGL 贴图受浏览器安全策略限制，**双击打开 index.html（file://）时图片纹理无法加载**。请任选一种方式启动本地服务：

```bash
# 方式一：Python（Mac/Linux 自带，Windows 装过 Python 即可）
cd game-vault
python -m http.server 8000

# 方式二：Node
npx serve game-vault

# 方式三：VSCode 插件
安装 "Live Server"，右键 index.html → Open with Live Server
```

然后浏览器访问 `http://localhost:8000` 即可。

### 添加一款游戏（3 步）

1. 把图片（jpg / png / webp）复制到 `assets/games/` 文件夹
2. 打开 `js/games-data.js`，在 `GAMES` 数组里复制一段 `{ ... }` 并修改
3. 保存并刷新浏览器

字段说明：

| 字段      | 必填 | 作用 |
|-----------|------|------|
| `name`    | ✅   | 游戏中文名（详情浮层大标题） |
| `name_en` | 否   | 英文名，悬停时显示的巨型标题（不填则用中文名） |
| `genre`   | 否   | 类型标签，如 `"太空探索 RPG"` |
| `year`    | 否   | 年份 |
| `desc`    | 否   | 一句话简介（详情浮层） |
| `image`   | ✅   | 图片路径，如 `"assets/games/xxx.jpg"` |
| `link`    | 否   | 「查看资源」按钮跳转地址（商店页/下载页/官网） |

- **数组顺序 = 画廊陈列顺序 = 时间线顺序**
- 建议图片：宽 1200–1600px（16:9 或 3:2）、jpg 格式、单张 < 400KB
- 文件名只用小写字母、数字、连字符（如 `zelda-totk.jpg`），避免中文和空格

### 修改站点信息

全在 `js/games-data.js` 顶部的 `SITE` 对象里：站名、首页大字、角落文案、页脚、联系邮箱、时钟时区、默认主题。

### 微调手感（可选）

在 `SITE` 里解开 `tuning` 注释即可调整：惯性粘度、自转速度、时间线间距、卡片大小、滚轮灵敏度、鼠标视差、黑白洗白程度。

## 🖥️ 交互说明

| 操作 | 效果 |
|------|------|
| 页面加载 | 真实纹理加载进度 → 双闸门开启 → 大字遮罩入场 |
| 移动鼠标 | 自定义圆点光标、相机视差 |
| 悬停卡片 | 卡片前推放大、**从黑白恢复彩色**、底部弹出巨字标题 |
| 滚动滚轮 | 第一段：3D 雕塑摊平为水平时间线；第二段：相机沿时间线巡览 |
| ← / → 方向键 | 时间线前后翻卡片 |
| 点击卡片 | 右侧滑出毛玻璃详情浮层（大图/名称/类型/简介/外链按钮），Esc 或点击任意处关闭 |
| 底部中央 | 环形 / 花形 / 星球 / 柱阵 四种 3D 布局切换 |
| 左下角 | 线稿模式（调试骨架视图） |
| 左上角 | 黑白 ⇄ 幻彩主题（幻彩 = 彩色渐变流动背景 + 卡片恢复彩色） |
| 屏幕 < 1024px | 自动降级为可滚动的卡片网格，手机也能正常浏览 |

## 🌐 部署上线

整站是纯静态文件，把 `game-vault/` 整个文件夹丢到任意静态托管即可：

- **GitHub Pages**：推送到仓库 → Settings → Pages → 选分支
- **Vercel / Netlify**：拖拽文件夹到控制台
- **自己的服务器**：nginx 指向目录，`index index.html;`

## ❓ 常见问题

- **图片不显示** → 检查路径大小写是否与文件名完全一致（线上服务器区分大小写）
- **页面紫色/黑色卡片** → 图片路径错了，或你在用 file:// 直开（见"快速开始"）
- **想关掉默认黑白效果** → 把 `SITE.theme` 改成 `"color"`
- **字体想换** → 改 `css/style.css` 顶部 `:root` 里的 `--font`
