# STEM 的平行空间 (STEM Parallel Space) - V1.0

一个专为高品质单机与独立游戏打造的沉浸式资源展馆。

## 第一版功能特性 (V1.0)
- **技术栈**：React 18 + TypeScript + Vite + Tailwind CSS + Framer Motion
- **核心组件**：
  - 3D 胶卷滚轴横向卡片轮播 (CinemaRoll & GameCard)
  - 沉浸式游戏详情剧场抽屉 (MediaDrawer & VideoTheatre)
  - 快速检索与多维类型标签筛选 (QuickListModal)
  - 官方高清预告片与实机截图画廊 (GalleryGrid & Lightbox)
